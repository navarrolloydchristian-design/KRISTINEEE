kristine's birthday surprise website

FILES
- index.html: the website
- assets/birthday-cat.jpeg: your uploaded birthday cat picture
- assets/surprise-video.mp4: your uploaded video present

PREVIEW
Double-click index.html to preview. Gift photos are loaded from Unsplash URLs, so an internet connection is needed for those images. The Spotify playlist appears on the second screen, before the yes/no question. Browsers may require a tap to start playback.

GITHUB PAGES
1. Create a public repository.
2. Upload index.html and the whole assets folder to the repository root.
3. Open Settings > Pages. Choose Deploy from a branch, branch main, folder /(root), then save.
4. Wait for the published URL to appear.

The personal letter is intentionally left blank. Type it into the letter section for preview, then add the final text to index.html before publishing if you want it saved for Kristine.
